# Deploy sofIA to Render

This guide shows you how to deploy both the **sofIA Payment Agent** and **WhatsApp Bridge** to Render.

## 🚀 Quick Deploy to Render

### Option 1: One-Click Deploy (Recommended)

[![Deploy to Render](https://render.com/images/deploy-to-render-button.svg)](https://render.com/deploy?repo=https://github.com/your-username/sofia-payment-agent)

### Option 2: Manual Deploy

1. **Fork this repository** to your GitHub account
2. **Connect to Render:**
   - Go to [render.com](https://render.com)
   - Sign up/login with GitHub
   - Click "New +" → "Blueprint"
   - Connect your forked repository

3. **Configure Environment Variables:**
   - `GOOGLE_API_KEY` - Your Google AI API key (required)
   - `JWT_SECRET` - Auto-generated by Render
   - `ENCRYPTION_KEY` - Auto-generated by Render

4. **Deploy:**
   - Click "Apply" to deploy both services
   - Wait for deployment to complete

## 📋 Render Configuration

### Services Created

1. **sofIA Payment Agent** (Python FastAPI)
   - URL: `https://sofia-payment-agent.onrender.com`

2. **WhatsApp Bridge** (Node.js)

**WhatsApp Bridge:**
```bash
SOFIA_API_URL=https://sofia-payment-agent.onrender.com

```

## 🔧 Manual Setup (Step by Step)

### 1. Create sofIA Payment Agent Service

1. **Go to Render Dashboard**
2. **Click "New +" → "Web Service"**
3. **Connect Repository:**
   - Select your GitHub repository
   - Choose the main branch

4. **Configure Service:**
   - **Name:** `sofia-payment-agent`
   - **Environment:** `Python 3`
   - **Build Command:** `pip install uv && uv sync --frozen`
   - **Start Command:** `uv run app.py`

5. **Set Environment Variables:**
   - `GOOGLE_API_KEY` = your Google AI API key
   - `HOST` = `0.0.0.0`
   - `PORT` = `8000`
   - `AGENT_ID` = `sofia-whatsapp-agent`
   - `MERCHANT_ID` = `sofia-merchant`

6. **Deploy:** Click "Create Web Service"

### 2. Create WhatsApp Bridge Service

1. **Click "New +" → "Web Service"**
2. **Connect Repository:**
   - Select the same GitHub repository
   - Choose the main branch

3. **Configure Service:**
   - **Name:** `whatsapp-bridge`
   - **Root Directory:** `whatsapp-bridge`
   - **Environment:** `Node`
   - **Build Command:** `npm install`
   - **Start Command:** `npm start`

4. **Set Environment Variables:**
   - `SOFIA_API_URL` = `https://sofia-payment-agent.onrender.com`
   - `PORT` = `3001`

5. **Deploy:** Click "Create Web Service"

## 🛠️ Troubleshooting

### Common Issues

**1. WhatsApp Bridge Not Connecting**
- Check Render logs for QR code
- Ensure WhatsApp session is cleared
- Restart the WhatsApp Bridge service

**2. Services Can't Communicate**
- Verify `SOFIA_API_URL` is correct
- Check both services are running
- Look for network errors in logs

**3. Google API Key Issues**
- Verify API key is set correctly
- Check API key has proper permissions
- Ensure no extra spaces in environment variable

**4. Build Failures**
- Check Python/Node.js versions
- Verify all dependencies are in requirements
- Look for build errors in logs

### Reset WhatsApp Session
```bash
# In Render dashboard, restart the WhatsApp Bridge service
# This will clear the WhatsApp session and show a new QR code
```
